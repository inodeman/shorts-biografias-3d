# Biografías 3D

Diez shorts biográficos en vertical (9:16), de **2 minutos 55 segundos** cada uno, con narración en español, música original y animación 3D.

Serie de InodeAi.

| # | Carpeta | Título |
|---|---------|--------|

| 03 | `03-nikola-tesla` | Nikola Tesla: el rayo que iluminó las calles |
| 04 | `04-marie-curie` | Marie Curie: la luz que también quema |
| 05 | `05-leonardo-da-vinci` | Leonardo da Vinci: el hombre que no eligió un solo oficio |

| 09 | `09-amelia-earhart` | Amelia Earhart: el cielo no tenía acompañante |
| 10 | `10-albert-einstein` | Albert Einstein: el oficinista que dobló el tiempo |

Cada carpeta incluye:

- `short.mp4` — video con audio, listo para subir
- `titulo.txt` — título
- `descripcion.txt` — descripción para YouTube
- `guion.txt` — narración completa

Las figuras se muestran de espaldas, en silueta o mediante sus lugares y objetos. No son retratos fotográficos.
